# 历史文档归档

本目录保存 ExamForge 迁移前的设计、计划和状态材料。它们是按当时日期、分支和环境记录的历史证据，不是当前 spec、ticket、项目状态或交付授权的事实源。

## 当前权威入口

- `CONTEXT.md`：领域术语、边界和不变量。
- `docs/adr/`：长期决策及其实现生命周期、证据和重访条件。
- GitHub Issues：当前 spec、ticket、依赖、验收、解决记录和活动状态。
- `docs/background/`：外部输入与历史验证证据，按其声明的时间和范围解释。

## 归档分区

- `design/`：旧的长期设计材料；阅读时以对应 ADR 和当前代码为准。
- `plan/`：旧的执行计划和提交记录；其中的分支、未 push、下一步描述只代表记录时点。
- `status/`：旧的项目状态和代码审查汇总；新的进度与审查闭环写在 GitHub Issues/评论中。

归档迁移不改写 `docs/temp/`。课程报告草稿和临时资产仍由该目录按原职责维护。

## 解释规则

归档文件若没有统一元数据，至少按文件内日期、source ref/commit、环境和正文范围解释；不得将历史记录中的“当前”“下一步”“未合并”直接当作今天的事实。新增决策应写入 ADR，不在归档文件中双写活动事实。
